# Lights Out v11.3.3

Small fixes on v11.3.2.

**Time format follows your region.** "Automatic" now follows the Windows
regional format (Settings › Time & language › Region), not the app's
language, so an English app on a 24-hour region shows 24-hour times.

**No lost Settings edits.** If you leave Settings and reopen it within a
moment, the panel waits for the reload to finish before it takes input, so
nothing you type can be overwritten.

**Tidier ritual dialog.** "Cancel ritual" is a quiet red text button with
room under Skip and Next, instead of a chip on the dialog's edge.

Assets: `Lights-Out-Setup-v11.3.3.exe`, `Lights-Out-Portable-v11.3.3-win-x64.zip`,
`SHA256SUMS.txt`, `BUILD-MANIFEST.json` and `WINDOWS-VERIFICATION.json`. Both
packages are unsigned.
