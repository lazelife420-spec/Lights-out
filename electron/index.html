          WiFi Guard Experimental

          Requires a compatible router or your own webhook. Windows Firewall on this PC cannot block a different phone or tablet on the LAN.

          Router integrations are model-dependent and experimental. Webhook is the most explicit integration. Adapter disables this PC's Wi-Fi entirely.

          Selecting a device blocks nothing by itself. Router and webhook methods receive the selected MAC addresses; Wi-Fi adapter mode ignores the list.

          Test Block also saves this Wi-Fi Guard setup.

          Content Blocker Hosts file

          Edits the Windows hosts file and may require administrator approval. Secure DNS, VPNs, and cached browser connections can bypass it.

          Used only when “Use default blocklist” is off. With the default list on, only the default sites are blocked.
